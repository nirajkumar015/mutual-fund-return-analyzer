# Mutual Fund Return Analyzer 📈

A web-based financial planning application built using **Python** and **Streamlit**.

## 🔗 Project Links

GitHub: https://github.com/nirajkumar015/mutual-fund-return-analyzer  
Live App: https://mutual-fund-return-analyzer-qjnvzpmjtf2ghttcs6tuaf.streamlit.app

## 🚀 Features

- SIP Calculator
- Lumpsum Calculator
- Tax-adjusted returns
- Inflation-adjusted (real) CAGR
- Goal-based financial planning
- Retirement planner
- Interactive growth charts
- Mobile-installable Progressive Web App (PWA)

## 🛠 Tech Stack

- Python
- Streamlit
- Pandas

## 📱 Mobile App

Open the Live App link in Chrome on Android and select  
**“Add to Home Screen”** to install it like a mobile app.
